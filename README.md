# Atividade de Revisão - JavaScript

## Objetivo

Realizar uma revisão dos principais conceitos básicos de JavaScript estudados em aula.

A atividade possui 35 exercícios organizados em ordem de dificuldade e separados por conteúdo.

Os exercícios utilizam os mesmos conceitos apresentados durante as aulas, porém com situações e exemplos diferentes.

## Como realizar

Abra os exercícios seguindo a ordem numérica.

Escreva sua solução abaixo dos comentários presentes em cada arquivo.

Para executar um arquivo:

```bash
node nome-do-arquivo.js
```

Exemplo:

```bash
node 01-dados-pessoais.js
```

## Orientações

- Não apague os comentários dos exercícios.
- Faça os exercícios na ordem.
- Teste cada código pelo terminal.
- Leia atentamente o que está sendo solicitado.
- Utilize somente os conceitos estudados até o momento.
- Evite copiar códigos prontos.
- Caso encontre um erro, leia a mensagem apresentada no terminal antes de pedir ajuda.

## Objetivo da revisão

Esta atividade tem como finalidade verificar a compreensão dos fundamentos de JavaScript antes de avançarmos para novos conteúdos.
